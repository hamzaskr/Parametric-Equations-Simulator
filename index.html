Where did the x-y path come from?

The parametric equations generate a pair (x(t), y(t)) for every value of t. Plotting all those pairs creates the actual geometric path. Eliminating t can give a Cartesian relationship such as y = ax² + bx + c, but that path no longer tells us when the object reaches each point. The parametric view keeps the timing.
